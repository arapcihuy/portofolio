## 📋 Deskripsi Proyek

Website portofolio pribadi yang dirancang untuk menampilkan profil profesional, pengalaman kerja, proyek terbaru, dan keahlian teknis. Website ini memiliki desain modern dengan fitur **Dark Mode** otomatis/manual dan formulir kontak yang terintegrasi dengan backend sederhana.

## 🎯 Fitur Utama

- **📱 Responsive Design**: Tampilan optimal di berbagai perangkat (Mobile & Desktop).
- **🌓 Dark/Light Mode**: Mendukung preferensi tema user dan sistem secara otomatis.
- **🖼️ Project Showcase**: Galeri proyek dengan dukungan video dan tag kategori interaktif.
- **⚓ Interactive Social Bar**: Navigation bar melayang dengan efek animasi hover yang premium.
- **📧 Contact Form**: Formulir yang berfungsi untuk mengirim pesan langsung ke server.
- **✨ Smooth Transitions**: Efek *fade-in* dan scroll-reveal untuk pengalaman pengguna yang elegan.

---

## 🛠️ Tech Stack

### **Frontend**
- **HTML5 & Vanilla JS** - Struktur dasar dan logika aplikasi.
- **Tailwind CSS** - Framework CSS untuk styling modern dan responsif.
- **Font Awesome** - Ikonografi pelengkap UI.
- **Inter Font** - Tipografi yang bersih dan mudah dibaca.

### **Backend**
- **Node.js & Express** - Server ringan untuk menangani formulir kontak.
- **File System (fs)** - Penyimpanan data pesan sederhana ke format JSON.

---

## 🚀 Instalasi & Pengembangan

### **Prasyarat**
- Node.js (versi terbaru)
- npm atau yarn

### **Langkah-langkah**

1. **Jalankan Backend (Untuk Form Kontak):**
   ```bash
   node server.js
   ```
   Server akan berjalan di `http://localhost:3000`.

2. **Buka Website:**
   Akses file `index.html` langsung melalui browser atau gunakan *Live Server* di VS Code untuk hasil terbaik.
