My Latest Projects

Jarialjabar Web

Jarilajabr – Website Les Berhitung dan Membaca (Halim, Jaktim) Website ini saya buat untuk Jarilajabr, sebuah tempat les yang menyediakan layanan belajar berhitung dan membaca untuk anak-anak di Halim, Jakarta Timur. Proyek ini saya kerjakan sendiri menggunakan HTML, CSS, dan JavaScript, lalu saya hosting di Firebase agar bisa diakses secara online. Desainnya saya buat responsif dan ramah pengguna, lengkap dengan tombol WhatsApp untuk langsung mendaftar kelas gratis. Fokus utama saya adalah menyampaikan informasi program les secara jelas dengan tampilan bersih dan mudah dinavigasi, baik lewat desktop maupun smartphone.

KINCLONG

Rumah Kinclong – Aplikasi Jasa Pembersih Rumah (UI/UX Design) Proyek ini adalah konsep aplikasi jasa kebersihan rumah yang saya rancang menggunakan Figma. Desainnya saya fokuskan agar pengguna bisa dengan mudah memilih bagian rumah yang ingin dibersihkan, seperti kamar, dapur, dan halaman, hanya dengan beberapa klik. UI-nya simpel dan modern, terinspirasi dari aplikasi layanan on-demand seperti Gojek atau CleanMyHouse. Tampilan ini disiapkan untuk keperluan presentasi dan prototyping, serta bisa dikembangkan lebih lanjut menjadi aplikasi mobile menggunakan framework seperti Flutter atau React Native.

Quondam

Quondam – Aplikasi Marketplace Jual Beli Barang (UI/UX Design) Quondam adalah desain aplikasi marketplace yang saya buat menggunakan Figma. Proyek ini dirancang untuk memudahkan pengguna dalam menjual dan membeli berbagai barang seperti gadget, kendaraan, furniture, dan lainnya. Di tampilan awalnya, saya menambahkan fitur-fitur penting seperti search bar, filter kategori, tujuan pengiriman, dan ikon login/daftar. Desain ini saya buat dengan pendekatan user-friendly dan clean, cocok jika nanti dikembangkan menggunakan React untuk frontend-nya atau Laravel jika ingin berbasis web backend.
